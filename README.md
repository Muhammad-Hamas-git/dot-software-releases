# dot Software releases

Downloads for dot's programs. The newest version is always under
[Releases](https://github.com/Muhammad-Hamas-git/dot-software-releases/releases/latest).

- **dotFilm** (video editor, Windows 10 / 11): `dotFilm-Setup.exe` installs it, `dotFilm-Portable.zip` runs without installing.
